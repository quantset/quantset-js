# QuantSet — Global Market Data, Quant Analytics & MCP for JavaScript / AI Agents

Official TypeScript SDK and Model Context Protocol (MCP) server for **[QuantSet](https://quantset.dev)** — **52,000+ global stocks across 67 countries** (US history back to 1962), **734 crypto pairs**, **42 FX currencies**, **hourly & live session bars**, **40+ factor stock screening**, **Wall Street consensus estimates**, **4,899 ETF look-through holdings**, **correlations & drawdowns**, **Treasury/TIPS yield curves**, and **reconciled financials**.

| Package | Install | Best for |
| --- | --- | --- |
| **[`@quantset/mcp`](mcp/README.md)** | `npx -y @quantset/mcp` | Giving Claude Desktop, Claude Code, Cursor & Codex live market superpowers |
| **[`quantset`](client/README.md)** | `npm install quantset` | Next.js dashboards, fintech backends, screeners & Node/Bun/Edge scripts |

Both packages run **immediately with zero signup** via the built-in `mw_demo` sandbox key. Unlock all 52,000+ symbols at **[quantset.dev/pricing](https://quantset.dev/pricing)**.
